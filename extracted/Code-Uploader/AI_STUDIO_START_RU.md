# Перенос «Личный Органайзер» в Google AI Studio — сначала прочитайте

## Что лежит в архиве
Это полная копия исходного рабочего пространства из `Code-Uploader.zip` с исходниками приложения, зависимостями workspace, настройками и приложенными материалами. Сохранены исходные имена и структура проекта. Удалены только история Git (`.git`) и локальный кэш Expo (`.expo`); история репозитория не нужна для сборки, а кэш привязан к прежней среде.

В архиве есть исходное приложение в `artifacts/organizer/`, скриншоты и приложенные PDF в `attached_assets/`, а также остальные пакеты рабочего пространства. Исходный код не запускался и не переписывался.

## Важное про Google AI Studio
Приложение сейчас написано на Expo / React Native / TypeScript. Нативный Android-режим Google AI Studio создаёт Kotlin + Jetpack Compose. Это не простое копирование одного формата в другой: попросите AI Studio перенести экраны и поведение по исходникам и скриншотам. Готовый перенос не гарантирует визуального совпадения без проверки поэкрано.

Официальные инструкции:
- Build mode: https://ai.google.dev/gemini-api/docs/aistudio-build-mode
- Android: https://ai.google.dev/gemini-api/docs/aistudio-android

В Build mode выберите платформу Android и начните проект. В Google AI Studio есть импорт репозитория из GitHub в Build mode; если он доступен в вашем Android-потоке, можно использовать репозиторий. Не рассчитывайте, что Expo ZIP автоматически откроется как готовый Kotlin-проект: используйте исходники как материал для миграции. После переноса проверьте результат в Android-эмуляторе и на телефоне.

## Что переносить и сверять
- Название: `Личный Органайзер`; исходный Android application ID: `com.heybo.organizer`.
- Язык интерфейса: русский; ориентация: портрет; основной зелёный цвет: `#2E7D32`.
- Экраны: главная, пароли, заметки, задачи, генератор паролей, экспорт, поиск, настройка PIN, настройки и «О приложении».
- Пароли и PIN, заметки (в том числе фото), задачи и параметры безопасности сейчас хранятся локально. Источник использует ключи `passwords`, `notes`, `todos`, `pin_code`, `pin_enabled`, `biometric_enabled`.
- В исходном экране экспорта отдельно указано, что экспорт заметок не включает изображения.
- Заметки позволяют прикрепить изображение; у задач есть приоритеты, статус и напоминания; поиск охватывает пароли, заметки и задачи.
- Сохраните офлайн-работу и не добавляйте сервер/Firebase без отдельной необходимости.

## Данные и публикация — не пропустите
Архив содержит код, но не данные из телефона и не ключ подписи Android. Перед переустановкой приложения экспортируйте резервную копию из старой версии и не удаляйте её, пока импорт данных в новую версию не проверен.

Если приложение уже опубликовано и новая сборка должна обновлять его в Google Play, одного совпадения application ID недостаточно: для обновления нужна совместимая подпись (тот же ключ загрузки / схема Play App Signing). В архиве нет keystore, а подпись, которой управляет AI Studio, может не совпасть с прежней. До публикации проверьте это в Play Console; не заменяйте ключ и не публикуйте новую сборку, пока не подтверждена совместимость.

Исходное приложение хранит чувствительные значения через AsyncStorage. В миграции попросите AI Studio не писать пароли или PIN в логи и использовать защищённое локальное хранение Android. Сначала сохраните совместимость и импорт резервной копии, затем проверьте безопасность хранения.

## Готовый запрос
Откройте `PROMPT_AI_STUDIO_RU.md`, приложите исходники и скриншоты, затем вставьте запрос целиком. Попросите AI Studio сначала составить карту экранов и данных по исходникам, а затем переносить приложение поэтапно; это помогает избежать потери функций.
