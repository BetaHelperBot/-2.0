# Запрос для Google AI Studio Build (Android)

Работай в режиме **Android** и создай нативное Android-приложение на Kotlin + Jetpack Compose. Переноси существующее приложение из папки `artifacts/organizer/` этого архива. Это миграция Expo / React Native в Kotlin/Compose, а не веб-приложение и не попытка запустить Expo внутри Android Studio. Используй исходные экраны, тексты, компоненты, настройки и изображения из проекта; для визуальной сверки изучи скриншоты в `attached_assets/`.

## Сначала проанализируй, затем меняй
1. Просмотри исходники всех экранов и компонентов приложения, `app.json`, `package.json`, локальные хранилища и скриншоты.
2. До написания кода выведи короткую таблицу: исходный экран/функция → Kotlin/Compose экран или модуль → способ хранения/Android API → что нужно проверить вручную.
3. Не выдумывай новые функции и не удаляй существующие. Если поведение из исходников неясно, отметь это и оставь решение для вопроса владельцу.
4. Переноси приложение частями, после каждой части проверяй сборку и запуск. В конце выдай список выполненных функций и список того, что не удалось воспроизвести один-в-один.

## Идентичность и визуальный стиль
- Название: «Личный Органайзер».
- Сохрани package/application ID `com.heybo.organizer`, если среда это позволяет; не меняй его без отдельного подтверждения.
- Русский интерфейс, портретная ориентация, зелёная тема (основной цвет `#2E7D32`, тёмно-зелёный экран запуска `#1B5E20`), исходный значок приложения из `artifacts/organizer/assets/images/icon.png`.
- Сверяй отступы, подписи, цвета, карточки, вкладки и состояния экранов со скриншотами из `attached_assets/`; не заменяй их произвольным дизайном.
- Используй Material 3 Compose, но добивайся внешнего вида исходного приложения, а не стандартного шаблона.

## Функции, которые надо сохранить
- Главная с переходами и сводной информацией.
- Пароли: добавление/просмотр/изменение/удаление, копирование в буфер обмена.
- Генератор паролей и копирование результата.
- Заметки: создание и редактирование текста, прикрепление фото, отображение обнаруженных ссылок/карточек ссылок.
- Задачи: приоритет, отметка выполнения, удаление, очистка выполненных и локальные уведомления-напоминания.
- Поиск по паролям, заметкам и задачам.
- Экспорт резервной копии: сохранить фактическое поведение источника; сейчас экспорт заметок не включает изображения.
- Настройки PIN и биометрической блокировки, экран ввода PIN, экран «О приложении».
- Сохранение данных на устройстве и работа офлайн. Не добавляй Firebase, вход, облачную синхронизацию или сервер без отдельного запроса.

## Хранение и переход с установленной версии
В исходнике используются AsyncStorage-ключи `passwords`, `notes`, `todos`, `pin_code`, `pin_enabled`, `biometric_enabled`. Не стирай и не перезаписывай данные молча. Сначала выясни схему объектов из исходников и предложи проверяемый импорт из JSON-резервной копии старой версии. Сохрани локальные данные и только после успешной проверки переключайся на новое хранилище.

Значения паролей и PIN чувствительны: не логируй их и не храни открытым текстом. Реализуй защищённое локальное хранение паролей/PIN с использованием подходящего хранилища Android/Keystore. Не отправляй данные на сервер.

## Android-возможности
Корректно обработай разрешения и состояния для выбора фото из галереи, уведомлений, биометрии и буфера обмена. Если какая-то функция ограничена эмулятором Google AI Studio, укажи это отдельно и не считай отсутствие аппаратной функции ошибкой приложения.

## Критерии готовности
- Проект компилируется и открывается в эмуляторе.
- Все перечисленные экраны и переходы присутствуют.
- Добавление, изменение, удаление и перезапуск сохраняют локальные данные.
- Напоминания, экспорт, фото, PIN и биометрия проверены отдельно (или ограничение среды ясно обозначено).
- Приложение визуально сверено со скриншотами; русские тексты не заменены английскими заглушками.
- Не публикуй приложение и не меняй подпись/идентификатор, не проверяй секреты и не удаляй файлы исходника без моего отдельного запроса.
